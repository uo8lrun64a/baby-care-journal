# 天津哪里的正规医院可以捐献精子？

> 更新时间：2026-09-19 (UTC+8)

前几天在网上看见说捐精还能有营养费，所以我也有点心动，但是也不知道哪里能捐，不好意思去医院问，所以想了解一下天津哪里的正规医院可以捐献精子？

天津目前还没有设立人类精子库，所以目前在天津本地是没有办法捐献精子的，因为捐精一定要到国家所授权的正规机构，也就是人类精子库进行捐献才行，可以考虑到其他精子库进行捐献，比如：

人类精子库分布在各个精子库

**1、北京：国家人口计生委科学技术研究所，地址位于北京市海淀区大慧寺路12号；**

**2、上海：上海交通大学医学院附属仁济医院，地址位于上海市浦东新区灵山路845号；**

**3、浙江：浙江省妇幼和生殖保健中心，地址位于浙江省杭州市西湖区古荡湾万塘路256号；**

**4、四川：四川大学华西第二医院：地址位于四川省成都市锦江区成龙大道一段1416号；**

**5、湖南：中信湘雅生殖与遗传专科医院，地址位于湖南省长沙市开福区湘雅路84号；**

**6、陕西：陕西省妇幼保健院，地址位于陕西省西安市新城区后宰门73号。**

除此以外，还有许多地方都有设立精子库，分布在国内各个省份，可以根据自己的实际情况进行选择，然后到官网查找地址和中心电话进行咨询。

前几天有朋友说他去捐精了，说还有补助，但是我担心他是骗我的，想知道在天津捐献精子有报酬吗？

是有报酬的，如果是合格的志愿捐精者，3个月内完成捐精，补贴总额度为5000元，如果超过3个月，半年内完成捐精，补贴总额度为4200元，其中每一次合格，可以领取200元的补助，如果没有合格的话，也可以领取50元的捐精补贴。

捐精成功后可以领取补贴

除了补贴之后，还有隐藏的报酬，那就是体检，因为精子的用途比较特殊，所以在捐精期间会对精液做一系列的检查，都是免费的，比如生殖功能检验、精液检查、遗传病学检测、染色体分析等，也能一定程度上了解自身的实际情况。

我是天津的，前几天看到说捐献精子还会有报酬，想着捐了也不会有什么事，所以也想去试试，想先了解一下天津捐献精子的流程是什么？

**在天津捐献精子首先要满足捐精的条件，必须是年龄在22-45岁之间的我国公民，身体健康，没有传染病、遗传病等，才能进行捐精，整个流程也比较简单，包括：**

**1、签知情同意书，并进行4次精液质量筛查（只有2次以上质量合格的志愿者，才能进入下一轮）；**

**2、进一步的健康体检和抽血化验检查；**

**3、捐献次数一般为10-15次，每次捐精前需要3-5天不排精；**

**4、完成最后一次捐精后6个月要做一次健康检查，检查合格所捐献的精液才能使用。**
